# Keep shell integration metadata-only

Mani's optional Shell Integration retains the ten most recent command lines and their exit codes, but never captures terminal output. Mani ranks those commands locally by fuzzy Command Path similarity, recency, and failure status, exposing only the highest-scoring command when it meets a minimum relevance threshold; otherwise it reports that no related command was found. `mani setup` offers to enable the integration, explains exactly what it records, and allows the user to skip it. When enabled, setup previews the exact idempotent line, asks before changing `.zshrc` or `.bashrc`, creates a backup, and offers manual instructions instead. Users provide Diagnostic Output explicitly by pasting or piping it, preserving useful failure context without turning Mani into a terminal session recorder.
