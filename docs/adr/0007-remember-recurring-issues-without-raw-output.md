# Remember recurring issues without raw output

Mani recognizes repeated mistakes offline through local, inspectable Issue Records. It fingerprints the Command Path, exit code, and Diagnostic Output after removing changing values such as paths, timestamps, line numbers, hashes, and IDs, then stores only that fingerprint, a sanitized label, the occurrence count, and the last-seen date. Raw output is discarded with the session, and a recurring issue may only prompt a Generated Draft that includes the existing Custom Guide for refinement—the guide still changes only after explicit review and save. The refinement policy defaults to three similar failures within 30 days; after dismissal, it asks again only when the guide changes or the occurrence count doubles. These values live in configurable policy settings so issue detection does not depend on hard-coded prompt thresholds.
