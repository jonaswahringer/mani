# Require review before saving generated guides

LLM-assisted help begins as an ephemeral Generated Draft and enters the Custom Knowledge Base only after explicit user review and save. Generation remains available when Official Documentation is missing, but the context review and draft preview must show a prominent “No official source available” warning and must never imply invented citations. This preserves the distinction between official documentation, untrusted model output, and user-owned guidance while avoiding silent changes to a long-lived knowledge base.
