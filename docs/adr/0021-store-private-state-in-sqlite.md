# Store private state in SQLite

Mani stores recent-command metadata and Issue Records in one SQLite database under the Private State Root, using write-ahead logging for atomic updates and safe concurrent access from multiple local shell sessions. Mani creates the directory with owner-only `0700` permissions and the database with `0600` permissions, relying on operating-system disk encryption rather than adding application-level encryption and key management in v1. `mani state summary`, `recent`, and `issues` make retained data inspectable; `mani state clear recent|issues|all` previews deletion and asks for confirmation, with `--yes` available for scripts. Guide Revisions remain ordinary diff files in the Knowledge Base Root, use a separate `mani history clear` operation, and the private database schema uses explicit migrations so later versions can evolve it safely.
